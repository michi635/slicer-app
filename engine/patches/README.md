# Patches auf OrcaSlicer

- `orcaslicer-android.patch` – unverändert übernommen aus
  [LucasCoraca/orcaslicer-android](https://github.com/LucasCoraca/orcaslicer-android/blob/9e495819ae7b07250ae8522d0a62f16cd3f3760e/patches/orcaslicer-android.patch)
  (AGPL-3.0), passend zu OrcaSlicer `1ee0b730`. Enthält den Android-Build der Abhängigkeiten und die Engine-Anpassungen;
  die GUI-Teile darin werden hier nicht gebaut.
- `local/*.patch` – eigene Korrekturen, in Namensreihenfolge danach angewendet.
